# 주간보고 자동 취합 웹 서비스 (HWPX 생성)

각 팀원이 웹 애플리케이션에서 소속 팀을 선택하고 주간보고(이번주 실적, 다음주 계획)를 작성하면, **팀당 단 1개의 표 셀(Cell)** 안에 자동으로 통합 누적되며, 버튼 한 번으로 깔끔하게 서식이 적용된 **한글 문서(.hwpx)** 를 다운로드받을 수 있는 서비스입니다.

---

## 주요 기능

1. **팀원별 웹 직접 작성**:
   - 소속 팀 선택 및 신규 팀 추가 지원
   - 이번주 실적 / 다음주 계획 항목 등록
   - 동일 팀의 다른 팀원이 작성하더라도 **해당 팀의 단 1개 셀(Cell) 안에 차곡차곡 누적**
2. **실시간 2열 표 미리보기**:
   - 1열(이번주 실적) / 2열(다음주 계획) 구조의 2열 표를 웹 화면에서 라이브로 확인
3. **한글(HWPX) 자동 생성 & 다운로드**:
   - 한글 표준 개방형 포맷인 `.hwpx` 파일 자동 빌드
   - 가독성 뛰어난 함초롬바탕 글꼴, 굵은 제목, 글머리 기호(`-`), 행간 서식 적용
4. **자동 저장 (Data Persistence)**:
   - 새로고침 시에도 기존 작성 데이터 유지 (`data_store.json`)

---

## 실행 방법 (Quick Start)

```bash
# 1. 의존성 패키지 설치
uv pip install -r requirements.txt

# 2. Streamlit 웹 애플리케이션 실행
uv run streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 접속하여 이용 가능합니다.
