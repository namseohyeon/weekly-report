# 주간보고 자동 취합 웹 서비스

팀별 이번 주 실적과 다음 주 계획을 작성하고, 웹 미리보기와 동일한 구조의 **동적 한글 문서(.hwpx)** 를 내려받는 Streamlit 서비스입니다.

## 주요 기능

- 팀별 이번 주 실적 및 다음 주 계획 등록·수정·삭제
- 실적 완료일과 작성자 관리
- A4 가로 2열 형태의 최종 문서 미리보기
- 한국 시간 기준 이번 주·다음 주 기간 자동 계산
- 다음 주 계획을 새 주의 이번 주 실적으로 이월
- 입력 데이터 자동 저장 및 이월 전 기록 보관

## 동적 HWPX 생성

`경영관리본부 주간 실적 및 계획.hwpx`를 OWPML 원본 양식으로 사용합니다. 누름틀에 여러 항목을 합치는 대신, 양식에 정의된 제목·내용 문단을 데이터 개수만큼 복제합니다.

- 출력 순서: `제목1 → 내용1 → 제목2 → 내용2`
- 제목: 휴먼명조 14pt, 굵게, 원형 글머리표
- 내용: 한양중고딕 12pt
- 내용 들여쓰기: 공백 2칸 뒤 `-`
- 내용량에 따른 셀 높이 자동 확장
- 두 번째 팀부터 팀명 앞 6pt 간격 적용
- 실적 날짜 자동 표시
- 내용이 없는 영역은 `-` 표시

현재 양식은 최대 2개 팀을 한 페이지에 표시하며, 각 팀의 실적·계획 항목 개수에는 제한이 없습니다.

## 실행 방법

Python 3.10 이상을 권장합니다.

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속합니다.

## 주요 파일

- `app.py`: 입력·수정·미리보기·다운로드 UI
- `dynamic_hwpx_generator.py`: OWPML 문단 및 표 동적 생성
- `hwp_generator.py`: 웹 미리보기 생성
- `경영관리본부 주간 실적 및 계획.hwpx`: HWPX 원본 양식
- `data_store.json`: 로컬 입력 데이터 저장 파일

## 사용 방법

1. 보고서 작성·수정 탭에서 팀을 추가합니다.
2. 이번 주 실적 또는 다음 주 계획을 입력합니다.
3. 최종 문서 미리보기·저장 탭에서 결과를 확인합니다.
4. `동적 한글(.hwpx) 다운로드` 버튼으로 문서를 내려받습니다.
