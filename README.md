# 주간보고 자동 취합 웹 서비스 (HWP 생성)

팀별 이번 주 실적과 다음 주 계획을 작성·수정하고, 최종 문서를 미리 확인한 뒤 **한글 문서(.hwp)** 로 다운로드할 수 있는 서비스입니다.

---

## 주요 기능

1. **팀별 보고서 작성·수정**:
   - 팀 선택 및 신규 팀 추가
   - 이번 주 실적 / 다음 주 계획 등록·수정·삭제
   - 실적 날짜와 작성자 관리
2. **최종 문서 미리보기**:
   - A4 가로 2열 양식을 웹에서 확인
   - 한국 시간 기준 이번 주와 다음 주의 월요일~금요일 자동 표시
3. **한글(HWP) 자동 생성 & 다운로드**:
   - 한글 프로그램에서 확인 가능한 `.hwp` 파일 자동 생성
   - 가독성 뛰어난 함초롬바탕 글꼴, 굵은 제목, 글머리 기호(`-`), 행간 서식 적용
4. **자동 저장 및 주간 이월**:
   - 새로고침 시에도 기존 작성 데이터 유지 (`data_store.json`)
   - 다음 주 계획 전체를 새 주의 이번 주 실적으로 이월
   - 이월 전 보고서를 `data/history`에 보관

---

## 실행 방법 (Quick Start)

```bash
# 1. 의존성 패키지 설치
uv pip install -r requirements.txt

# 2. Streamlit 웹 애플리케이션 실행
uv run streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 접속하여 이용 가능합니다.
